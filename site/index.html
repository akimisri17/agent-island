Know which agent is waiting on you.

A menu-bar app for people who run Claude Code, Codex, Cursor and Antigravity all day. It shows which session needs you, where you stand against your usage limits, what got done today, and what your repositories and scheduled tasks need. Nothing leaves your machine.

Download for macOS or Windows View on GitHub

Waiting

One key to the session that needs you

Press ⌃⌥J from anywhere and the session that has waited longest comes to the front. The count next to the menu-bar icon tells you how many are waiting.

  • Finished: the agent ended its turn and is waiting for your next message.
  • Tool running or needs approval: a tool call has gone more than 20 seconds without a result.
  • Lands on the exact Terminal or iTerm tab, the right VS Code or Cursor window, or the Claude app.
  • Cut off by the limit: after a Claude limit resets, the sessions it stopped come back with a Resume button.
  • Choose your own shortcut in Settings.

Limits

Where you stand, without made-up numbers

Claude's logs only record the moment you hit a limit, and the limit is shared with claude.ai and desktop chats, which leave no trace on your machine. So instead of a guessed percentage you get what is actually known.

  • When you're limited: the exact reset time Claude logged.
  • Otherwise: how this window compares with the usage before your past limit hits.
  • Codex: the official percentage used, with "full in about N minutes".
  • One suggested move when you're close, and a notification once per window.

Today

Your standup, already written

What agents did today, project by project: time, which agents, session titles, files touched, and the day's git commits. Plus what is still waiting and which session to pick up next.

  • Copy standup puts it on your clipboard as plain text.
  • Polish with Claude (optional, off by default) rewrites it through your own claude command.

Repos

What each repository needs, and the button for it

One row for each repository your agents worked in today: the branch, and what you'd do next in plain words. The ones that need you come first.

  • Pull fast-forwards only, and shows the command before it runs.
  • Delete old branches that were merged or deleted on the remote, after you confirm.
  • Terminal opens your terminal app in that folder.
  • Recipes keep your kick-off prompts per repository. Start opens a new Claude session with one.

Tasks

Scheduled tasks that quietly didn't run

Your scheduled Claude tasks, with how the last seven days went. A red dot on the tab when one needs a look.

  • Missed: it hasn't run when it usually does.
  • Stopped: it got stuck, often waiting for an approval nobody gave.
  • Run now starts it; Last run opens what happened.

Wrapped

Your last 30 days with agents

Agent-hours, hours your agents waited on you, limit hits, peak parallel agents, models by maker, and where the tokens went. You get one of 19 personas with two badges, and a share card that holds numbers only.

  • Filter by agent or by model maker: Anthropic, OpenAI, xAI, Google.
  • See where you approve the most, and allow routine build and test commands in one step.
  • A full HTML report opens in your browser and stays on your machine.

Any model those agents call shows up automatically: Claude, GPT, Grok, Gemini, Qwen, DeepSeek.

Privacy

It lives on your laptop

Nothing is sent

No account, telemetry, analytics or server. The one exception is the optional recap polish, which uses your own claude command and only runs when you click it.

Read-only

It reads agent logs and databases without changing them, and it never writes files next to them. A test checks that. Pull, branch cleanup and allow-rules run only when you confirm.

Not your prompts

It counts messages, tools and time. Prompt text is never stored or shown.

No special permissions

No screen recording, Accessibility or keychain access. Jumping to a Terminal tab asks once to control that app.

Light on battery

Nothing animates. A quick check runs once a minute (about 35 ms), and the full read only happens when you open the panel.

Open source

MIT licensed. Read every line on GitHub, and build it yourself if you prefer.

Install

Get Agent Island

  1. Download the installer for your system from the Releases page: a .dmg for macOS (Apple silicon or Intel), or a .msi or .exe for Windows.
  2. Allow it once. The builds are not signed yet, so macOS says it "could not verify" Agent Island. Click Done, open System Settings → Privacy & Security, and click Open Anyway next to "Agent Island" was blocked. Or run xattr -dr com.apple.quarantine "/Applications/Agent Island.app" once in Terminal. On Windows, click More info and then Run anyway.
  3. Click the icon in your menu bar or system tray, or press ⌃⌥J.

Prefer to build it yourself? You need Node 20+ and Rust. Instructions are in the README.
